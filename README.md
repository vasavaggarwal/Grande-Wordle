# GrandeWordle

Wordle Results, but with Ariana Grande's colors.

**GrandeWordle** takes your regular Wordle results and represents them using Ariana Grande's various colors over the years

-   ⬛ Black tiles → Blackface Ariana Grande
-   🟨 Yellow tiles → Yellowface Ariana Grance
-   🟩 Green tiles → Starbucks. Obviously.

Paste your Wordle results, generate your masterpiece, and share it with
the world. That's pretty much it.

## 🌐 Try it out

**[grandewordle.vercel.app](https://grandewordle.vercel.app)**

The website is hosted on Vercel, and this is the primary way to access
and use it. No installation needed if you just want to play around with
it!

## 🛠️ Run it locally

Want to run your own copy? Here's how:

**1. Clone the repository**

``` bash
git clone https://github.com/vasavaggarwal/Grande-Wordle.git
cd GrandeWordle
```

**2. Install dependencies**

``` bash
npm install
```

**3. Start the development server**

``` bash
npm run dev
```

Open the local URL displayed in your terminal (usually
`http://localhost:5173`).

**4. Build for production (optional)**

``` bash
npm run build
```
